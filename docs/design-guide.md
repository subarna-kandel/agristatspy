# Field Design Guide

This guide covers creating, configuring, and verifying field layouts in AgriStatsPy.

---

## 1. Completely Randomized Design (CRD)

### Concepts
In a CRD, treatments are allocated randomly across all experimental units without any grouping or blocking factor.

### Parameters
- `treatments` or `n_treatments`: Names of treatments or treatment count.
- `replications`: Number of independent units per treatment.
- `seed`: Integer for reproducible randomization.
- `plot_prefix`: Identifier prefix for plot numbering (default: `"P"`).
- `start_plot`: Starting number for plot identifiers (default: `1`).

### Display Modes
CRD supports two rendering modes:
- `grid`: Displays experimental units in rows and columns.
- `sequence`: Displays experimental units in serial sequence.

```python
import agristatspy as ag

design = ag.design.crd(n_treatments=4, replications=5, seed=10)
print(design.text_layout(mode="grid", row_length=5))
```

---

## 2. Randomized Complete Block Design (RCBD)

### Concepts
RCBD is suitable when field conditions vary along a known gradient (slope, fertility, irrigation distance). Plots are partitioned into blocks perpendicular to the gradient, such that plots within each block are as homogeneous as possible.

### Key Rules
- Every block must contain every treatment exactly once.
- Treatment allocations are independently randomized within each block.
- In `rcbd()`, the `replications` argument specifies the number of blocks ($b$). Total plots = $k \times b$.

### Display Options
RCBD displays distinct blocks with customizable dividers:

```python
design = ag.design.rcbd(
    treatments=["Variety_A", "Variety_B", "Variety_C"],
    replications=3,
    seed=101,
)

# Text layout with prominent block dividers
print(design.text_layout(block_separator=True, separator="="))
```

---

## 3. Invariant Validation

Every design generated by AgriStatsPy automatically validates internal invariants upon creation:
- Plot IDs are distinct and non-duplicated.
- Exact unit counts are preserved ($k \times r$).
- In RCBD, each block contains all treatments with no repeats.

You can explicitly re-check invariants at any time using:

```python
design.validate()  # Returns True or raises ValidationError
```
